# HTH — Heart to Heat

YMv1.2 モーションエディター（Web版）の公開ページです。

- 開く: https://rara-crash.github.io/hth-editor/
- 単一HTMLファイルで動作します（`index.html`）。モーションの作成・編集と、Web Serial による機体接続に対応します（Chrome系ブラウザ推奨）。
- 本体プロジェクトは YMv1.2 側で開発中です。このリポジトリは公開配布用です。

## 試作ページ

- [ICSマネージャー試作](https://rara-crash.github.io/hth-editor/ics-manager.html) — ICS3.5/3.6 の接続・ID管理・パラメータ読み書き（Web Serial）。実機がなくてもデモモードで操作感を確認できます。
- [3Dツイン試作](https://rara-crash.github.io/hth-editor/twin-3d.html) — 分解ビュー＋パーツ選択＋関節プレビューの試作。
- [3Dツイン試作・実機モデル版](https://rara-crash.github.io/hth-editor/twin-real.html) — 実機のSTEPモデルを変換した実寸ツイン（分解・パーツ選択）。
