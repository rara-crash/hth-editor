仕様メモ

実装は近藤科学『ICS3.5/3.6 ソフトウェアマニュアル コマンドリファレンス』に基づきます。CMD上位3bit: 100=Position / 101=Read / 110=Write / 111=ID、下位5bit=ID。サブコマンド: 0x00 EEPROM / 0x01 STRC / 0x02 SPD / 0x03 CUR / 0x04 TMP。ポジションは 7500 が中立、3500–11500、データは7bitずつ2バイトに分割。単線バスのため送信コマンドがそのままエコーで戻り、応答はその後ろに続きます（このログでも echo を表示）。通信設定: 8bit・偶数パリティ・フロー制御なし。実機での最終確認は未実施です。
